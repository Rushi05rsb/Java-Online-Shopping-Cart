# 🛒 Java Online Shopping Cart

## 📌 Project Overview

The **Online Shopping Cart System** is a basic shopping application developed using Java. It allows customers to explore products, add items to a shopping cart, calculate the total amount, apply discounts, and manage orders.

This project demonstrates Object-Oriented Programming (OOP) concepts in Java, along with basic web technologies such as HTML, CSS, and JavaScript.

## 🎯 Project Objectives

- To develop a basic online shopping cart application using Java.
- To understand and implement Object-Oriented Programming concepts.
- To manage products, customers, and shopping cart operations.
- To implement different discount and payment methods.
- To understand the integration of Java with web technologies.

## ✨ Features

- **Product Management:** Manage product details and information.
- **Customer Management:** Store and manage customer information.
- **Shopping Cart:** Add products and manage cart items.
- **Order Management:** Create and manage customer orders.
- **Discount System:** Implement flat and percentage-based discounts.
- **Payment Methods:** Support cash, card, and UPI payment demonstrations.
- **Web Interface:** Basic frontend developed using HTML, CSS, and JavaScript.

## 📚 OOP Concepts Implemented

This project demonstrates the following Object-Oriented Programming concepts:

1. **Encapsulation:** Organizing data and related methods within classes.
2. **Abstraction:** Defining common behaviours through interfaces and abstractions.
3. **Inheritance:** Reusing and extending existing class functionality.
4. **Polymorphism:** Supporting different implementations of payment and discount operations.

## ▶️ How to Run the Project

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in a Java-supported IDE such as VS Code, Eclipse, or IntelliJ IDEA.
4. Configure the Java development environment.
5. Run the `Main.java` file from the `com.shoppingcart` package.

The project also contains frontend files in the `web` directory.
